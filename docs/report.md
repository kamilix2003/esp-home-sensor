# ESP home sensor
Embedded electronics and avionics project
Kamil Chaj 418269

## Description

Wireless ESP32-C6 based home enviormental sensor powered by single Li-ion 18650 cell, running ESPhome firmware optimized for battery life which is to be measured in months instead of days.

## Requirements

- Li-ion cell protection and charger circuits
- Enviermental sensing: Temperature, Humidity, CO2, Viotile gases
- Light sensing
- Battery voltage monitoring
- Expension connectors: other sensors, e-ink display
- Low power consumption during deep sleep
